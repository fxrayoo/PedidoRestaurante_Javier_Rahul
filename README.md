Empezamos creando Estado_pedido.java: Que define los posibles estados en los que está un pedido para poder controlar y organizar su proceso
Continuamos creado la clase principal que seria PedidoRestaurante.java para poder agregar productos al pedido y calcular el total o los cambios en el estado del pedido.
Por último Main.java que es la clase desde donde se ejecutaría el programa. Este se encarga de crear pedidos, añadir artículos y comprobar si las reglas se cumplen.
Respecto a las reglas que se le han implementado; El sistema restringe cada pedido a un máximo de 5 artículos y bloquea la edición de productos una vez que el pedido aparezca en estado "Abierto".
